## 3. Results

### 3.1 RQ1：时间盲法下，LLM 单模型分类准确率如何？

**口径说明（双口径）**：
- **全对全准确率**：所有样本计分，VUS（Uncertain significance）视为错误——衡量"临床可用性"
- **表态时准确率**：仅统计模型输出明确 P/B 的样本——衡量"模型敢下结论时的可靠性"

**表 1｜单模型全对全准确率 × 金标准分层（n=5,000）**

| Model | All | Gold-A strict (n=100) | Gold-A broad (n=3,131) |
|---|---|---|---|
| Qwen3.7-Max | **68.3%** | 82.0% | 66.7% |
| Kimi-K2.6 | 67.0% | 90.0% | 63.7% |
| MiMo V2.5 Pro | 66.1% | **92.0%** | 63.2% |
| DeepSeek V4-Pro | 58.4% | 90.0% | 54.5% |
| DeepSeek V3-Chat | 49.4% | 69.0% | 42.5% |
| DeepSeek V3-Coder | 49.2% | 68.0% | 42.4% |

（Gold-A strict = ReviewStatus ∈ {expert panel, practice guideline}；broad = strict ∪ {multiple submitters, no conflicts}）

**发现 F1（厂商分层）**：非 DeepSeek 厂商（Qwen/Kimi/MiMo）全对全准确率 66-68%，显著高于 DeepSeek V3 系（49%），V4-Pro 居中（58.4%）。多厂商评估揭示：DeepSeek 的保守策略（VUS 弃权率高）系统性压低全对全指标，单厂商研究（如仅测 DeepSeek）会低估 LLM 变异解读的临床可用性。

**发现 F2（金标准分层效应）**：所有模型在 Gold-A strict 子集上准确率提升 +14~+26pp（MiMo 92%、Kimi/V4-Pro 90% vs 全体 58-68%）。专家评审标签噪声更小 → LLM 真实能力被 ClinVar 汇总标签的噪声低估。反过来说：ClinVar 汇总标签中存在系统性标签噪声（尤其 single-submitter 变异），用其评估 LLM 需谨慎。

### 3.2 RQ2：模型"敢表态"与"表态准"的关系

**表 2｜表态率 vs 表态时准确率**

| Model | Decisiveness (non-VUS) | Accuracy when decisive | Overall accuracy |
|---|---|---|---|
| DeepSeek V3-Coder | 49.9% | **98.7%** | 49.2% |
| DeepSeek V3-Chat | 50.1% | **98.6%** | 49.4% |
| Kimi-K2.6 | 68.4% | 97.8% | 67.0% |
| Qwen3.7-Max | 70.9% | 96.3% | 68.3% |
| DeepSeek V4-Pro | 72.1% | 80.9% | 58.4% |
| MiMo V2.5 Pro | 77.5% | 85.2% | 66.1% |

**发现 F3（表态即正确）**：所有模型在"明确表态"时准确率 ≥80.9%，其中 Kimi/chat/coder 达 97.8-98.7%，且假阳性率极低（共识：金标准 Benign 被判 Pathogenic 仅 45/2,500 = 1.9%）。当 LLM 输出"Pathogenic"时，几乎可以信任。

**发现 F4（敢表态 × 表态准 = 独立维度）**：Qwen/Kimi 双优（67-68% + 96-98%）；v4-pro/MiMo 敢表态（72-78%）但表态准确率降至 81-85%（推理型模型更"自信"但误报率 ×5）；chat/coder 保守但表态极精（98.6-98.7%）。模型选择应依据应用场景：筛查用双优模型，复核用保守模型。

**发现 F5（V3→V4 代际的真实含义）**：DeepSeek 从 V3（chat/coder）到 V4-Pro，全对全提升 9pp 主要来自表态率 +22pp（50%→72%），而表态准确率反而下降（98.7%→80.9%）。**代际升级买的是"敢说"，不是"说得对"**——对"更大模型 = 更可靠"的直觉提出反例。

### 3.3 RQ3：多模型共识投票能否提升可靠性？

**图 3｜6 模型共识混淆矩阵**：P 敏感度 95.1%、B 敏感度 13.8%、假阳性 45/2,500。

**表 3｜共识规模效应**

| 投票组合 | 全对全准确率 |
|---|---|
| DeepSeek V3 双模型（2 保守） | 49.1% |
| + Kimi（3 模型） | 49.4% |
| + MiMo（4 模型） | 54.5% |
| + Qwen（5 模型） | 56.8% |
| + V4-Pro（6 模型） | 57.2% |
| 最佳单模型（Qwen） | **68.3%** |

**发现 F6（共识增益的条件性）**：多数投票的增益取决于模型多样性——全保守模型组合下共识无效（49.1%），加入敢表态模型后逐级提升（+8.1pp），但 6 模型共识（57.2%）仍显著低于最佳单模型（Qwen 68.3%）。**模型选择优于投票**：当保守派占多数时，多数投票被拖累。这直接挑战"多模型共识 = 更强"的流行假设（如 AI-CURA 的 3 模型共识方法）。

**发现 F7（弃权模式的相关性）**：模型间分歧仅 9.4%（471/5,000），且分歧集中于"P vs VUS"而非"P vs B"——共识无法解决系统性弃权，只能过滤个别噪声。

### 3.4 RQ4：置信度校准

平均置信度 0.73-0.80 与全对全准确率 49-68% 显著不匹配（置信度-准确率差距 12-29pp）。LLM 的 confidence 字段**不可用于临床决策门槛**（Brier score 等严格校准指标见 Supplementary）。

### 3.5 时间盲法有效性

全部 5,000 变异 LastEvaluated ≥ 2026-01，晚于所有被测模型的知识截止（DeepSeek V4：2025-12；Qwen/Kimi/MiMo：≤2025 中）。模型无法通过记忆 ClinVar 历史标签作答，报告数字反映真实泛化能力。（泄漏敏感性分析：与 2025 前标签子集的对比见 Discussion/Supplementary。）

## 4. Discussion 要点（草案）

1. **临床可用的姿势**：LLM 变异解读的正确用法是"单边决策支持"——输出 Pathogenic 时高置信采纳（假阳性 1.9%），输出 VUS/Benign 时转人工。不建议作为排除诊断工具（B 敏感度仅 13.8%）。
2. **建议流程**：Qwen/Kimi 初筛（高检出）→ DeepSeek V3 系复核（表态即 98.6%）→ 双模型分歧转专家。
3. **厂商策略可解释性**：保守 vs 敢表态是训练策略（RLHF 奖励设计）的直接体现，非能力差异——厂商可通过校准目标调整。
4. **对 ClinVar 生态的启示**：单提交者标签噪声是 LLM 评估的主要混淆项；呼吁在 ClinVar 标签上提供置信度分层。
5. **对共识文献的修正**：AI-CURA 等报告的"共识增益"在模型多样性不足时不可复现——需报告模型多样性指标。
6. **局限**：单次调用（temperature=0）；无 gnomAD AF 输入（等位频率缺失加剧 Benign 弃权——AF 对照实验进行中）；引用编造验证未完成；标签时间线用 LastEvaluated 近似（严格应用 RCV 提交日期）。
