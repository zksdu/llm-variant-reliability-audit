## 一、研究定位

### 标题（候选）
*When Data Leakage Is Controlled: A Multi-Model Reliability Evaluation of LLM-Based ACMG/AMP Variant Classification*

### 一句话
当训练数据泄漏被时间盲法控制后，10+ 个 LLM 的 ACMG/AMP 变异致病性分类还可靠吗？

### 为什么是空白（2026 现状）
- **顶刊已证明可行**：AI-CURA（DeepSeek-R1 做 ACMG 分类，96% 一致率）2026-06 发表于 *Science Translational Medicine*；ClinVar-BERT 发表于 *Genome Medicine* 2026
- **数据泄漏是公认但未解决的问题**：LLM 训练语料含 ClinVar/ClinGen，现有准确率数字不可解释为泛化能力
- **ClawBench（2026-06 bioRxiv）刚提出时间盲法框架，但没有跨模型结果**——空窗期

### 新颖性（审稿人买账的 5 点）
1. **时间盲法分割**：用模型训练截止后发布的 ClinVar 标签做真值，系统性控制泄漏（首个大规模结果）
2. **10+ 模型共识投票**：单模型 vs 多数投票的增益量化（现有研究仅小规模验证）
3. **每 ACMG 规则错误分类学**：PVS1/PS1/PM2/PP3 等逐规则错误分析
4. **证据编造检测**：LLM 引用验证（是否虚构文献/证据）
5. **每变异成本科学**：$ per classified variant 跨模型对比

### 时间盲法设计（核心）
- 取**模型训练截止日期之后**提交/发布的 ClinVar 标签作为真值（确保 LLM 训练时没见过答案）
- 用 RCV 提交日期而非 release 日期重建时间线（严谨性要求）
- 该子集即测试集；训练截止前的数据仅用于 prompt 上下文（不参与评估）

## 四、实验设计

### 模型面板（10+）
- **DeepSeek 全量**：V4-pro（主）、V4-flash
- **国外模型子集**（500 变异）：GPT、Claude、Gemini
- **国产开放模型**：Qwen、GLM、Kimi（若 API 可用）

### 流程（每变异）
1. 提取变异信息（基因/转录本/cDNA/蛋白变更 + gnomAD AF）
2. 构造 prompt（ACMG 规则 + 变异描述 + 人群频率）
3. LLM 输出分类 + 证据 + 引用
4. 与 ClinGen/ClinVar 金标准对照
5. 记录：分类、置信度、引用、耗时、成本

### 评估指标
- 准确率（泄漏控制前后对比）、一致性（Kappa）
- 共识增益（多数投票 vs 单模型）
- 逐规则错误率、证据编造率
- $ per variant、延迟

### 规模与成本（已确认预算 ~$2,000）
- 全量：~5,000 变异 × 10+ 模型（DeepSeek 全量）
- 子集：500 变异 × GPT/Claude/Gemini
- DeepSeek 侧 ~$200-800；国外模型 ~$1,000-2,000

## 九、Pilot 实验结果（100 变异 × 3 模型，2026-08-04）

### 设置
- 测试集：时间盲法 100 变异（Pathogenic 48 / Benign 52），ClinVar LastEvaluated ≥ 2026-01
- 模型：deepseek-v4-pro（max_tokens=8192）、deepseek-chat、deepseek-coder（temperature=0）
- 提示词：ACMG/AMP 2015 五分类 JSON 输出（变异名/HGVS/基因，**无 gnomAD AF**——variant_summary 无此列）

### 结果 1：全对全准确率（VUS 计为错误）——临床可用性口径

| 方法 | 准确率 |
|---|---|
| deepseek-v4-pro | 59.0% |
| deepseek-chat | 50.0% |
| deepseek-coder | 49.0% |
| 3 模型共识 | 49.0% |

### 结果 2：明确表态时准确率（排除 VUS 弃权）——可靠性口径

| 方法 | 表态数/100 | 准确率 |
|---|---|---|
| deepseek-v4-pro | 68 | 86.8% |
| deepseek-chat | 50 | **100.0%** |
| deepseek-coder | 49 | **100.0%** |
| 3 模型共识 | 49 | **100.0%** |

### 结果 3：混淆矩阵（共识，金标准 P/B 各 48/52）

| | 金标准=P | 金标准=B |
|---|---|---|
| 模型=P | 44 | 0 |
| 模型=B | 0 | 5 |
| 模型=VUS | 4 | 47 |

→ Pathogenic 敏感度 91.7%（44/48）；**Benign 敏感度仅 9.6%（5/52）**；
→ 误报为 P 的 Benign = 0（无假阳性）。

### 核心发现（Pilot 叙事，待全量确认）

1. **表态即正确**：LLM 敢下结论时准确率 86.8-100%，无一例把 Benign 误判为 Pathogenic（假阳性=0）——决策支持场景下"AI 输出 P"高度可信
2. **系统性 Benign 弃权**：90.4% 的 Benign 变异被归为 VUS；模型对"阴性"极度保守
3. **无 AF 信息的场景缺陷**：prompt 未提供等位基因频率（BA1/BS1 规则无法应用），这是 Benign 弃权的主因之一——后续实验应加 gnomAD AF 对照
4. **共识无增益**：3 模型 VUS 弃权模式高度相关（都保守），多数投票无法挽救 → 提示"共识提升"需模型多样性
5. **置信度虚高**：平均置信度 0.74-0.78 与 49-59% 全对全准确率不匹配（校准差）

### 数据修复记录
- variant_summary 表头首列为 `#AlleleID`（带 `#`），preprocess 早期版本未剥离 → AlleleID 全空
- 修复：`header = [h.lstrip("#") for h in header]` + 流式重建 temporal（rebuild_temporal.py）
- 实验 CSV 主键按 (GeneSymbol, ClinicalSignificance) 双重校验逐变异恢复（restore_alleleids.py，100/100 通过）
- 采样脚本补单变异去重（原注释承诺去重但未实现；ClinVar 同 AlleleID 多行 ~4.9%）

## 十、全量中间结果（4 模型 × 5000 变异，2026-08-04/05）

### 设置
- 测试集：时间盲法 5000 变异（P=2499 / B=2500，单变异去重，LastEvaluated ≥ 2026-01）
- 模型：deepseek-chat / deepseek-coder / kimi-k2.6 / mimo-v2.5-pro（各 5000 全量）
- 进行中：deepseek-v4-pro（~500/5000）、qwen3.7-max（~200/5000）

### 单模型 × 金标准分层

| 模型 | 全对全准确率 | 金A严（100 专家评审）| 金A宽（3131）| 表态率 |
|---|---|---|---|
| deepseek-chat | 49.4% | 69.0% | 42.5% | 50.1% |
| deepseek-coder | 49.2% | 68.0% | 42.4% | 49.9% |
| kimi-k2.6 | **67.0%** | **90.0%** | 63.7% | 68.4% |
| mimo-v2.5-pro | **62.8%** | **85.0%** | 60.5% | ~65% |
| 4 模型共识 | 54.5% | 87.3% | 48.1% | — |

### 明确表态时准确率（排除 VUS 弃权）
- chat 98.6%（2505 表态）/ coder 98.7%（2495）/ kimi 97.8%（3422）/ mimo ~97%
- → 所有模型表态时 ~97-99%，**差异全在"敢不敢表态"**

### 混淆矩阵（chat+coder 共识，n≈4900）
- P 敏感度 88.5%（2200/2487）、B 敏感度 8.9%（216/2433）、假阳性 1.3%（32/2500）
- B 变异弃权率 87-91%，P 变异弃权率仅 11.5%

### 核心发现（全量确认 + 新增）
1. **表态即正确**（5000 规模确认）：模型敢下结论时 97.8-98.7% 准确，假阳性仅 1.3%
2. **系统性良性弃权**（确认）：87-91% 的良性变异被归 VUS——模型只敢说"致病"或"不知道"
3. **跨厂商保守度分层**（新增）：Kimi/MiMo（敢表态）全对全 63-67% vs DeepSeek（保守）49%——训练策略决定保守度，不影响表态准确性
4. **共识增益的条件**（新增）：加入敢表态模型后共识从 49.4%→54.5%（+5pp）；但共识仍 < Kimi 单模型 67%——保守模型占多数时投票被拖累，"模型选择比投票更重要"
5. **金标准 A 效应**（新增）：专家评审子集上所有模型 +20pp（chat/coder 68-69%、Kimi 90%、MiMo 85%）——金标准越权威模型表现越好

### 临床建议（论文结论雏形）
- Kimi/MiMo 适合作筛查（检出率高），DeepSeek 系适合作确认（保守但同样准）
- 建议流程：敢表态模型初筛 + 保守模型复核 + 双模型分歧转人工

## 十、终版结果（6 模型 × 5000 变异，30,000 次调用，2026-08-06）

### 设置
- 测试集：时间盲法 5000 变异（P=2499 / B=2500，单变异去重，LastEvaluated ≥ 2026-01）
- 模型面板：deepseek-v4-pro / deepseek-chat / deepseek-coder / kimi-k2.6 / mimo-v2.5-pro / qwen3.7-max（各 5000 全量）

### 单模型 × 金标准分层（全对全口径，VUS 计错）

| 模型 | 全体 | 金A严（100 专家评审）| 金A宽（3131）|
|---|---|---|---|
| qwen3.7-max | **68.3%** | 82.0% | 66.7% |
| kimi-k2.6 | 67.0% | 90.0% | 63.7% |
| mimo-v2.5-pro | 66.1% | **92.0%** | 63.2% |
| deepseek-v4-pro | 58.4% | 90.0% | 54.5% |
| deepseek-chat | 49.4% | 69.0% | 42.5% |
| deepseek-coder | 49.2% | 68.0% | 42.4% |
| 6 模型共识 | 57.2% | 92.6% | 51.8% |

### 明确表态时准确率（排除 VUS 弃权）——关键权衡

| 模型 | 表态率 | 表态时准确率 |
|---|---|---|
| kimi-k2.6 | 68.4% | **97.8%** |
| deepseek-chat | 50.1% | **98.6%** |
| deepseek-coder | 49.9% | **98.7%** |
| qwen3.7-max | 70.9% | 96.3% |
| deepseek-v4-pro | 72.1% | 80.9% |
| mimo-v2.5-pro | 77.5% | 85.2% |
| 6 模型共识 | 52.8% | 98.2% |

### 混淆矩阵（6 模型共识，n≈4528）
- 模型=P: 金P 2305 / 金B 45（假阳性率 1.9%）
- 模型=B: 金P 3 / 金B 284
- 模型=VUS: 金P 117 / 金B 1774
- P 敏感度 95.1%（2305/2425）、B 敏感度 13.8%（284/2058）

### 核心发现（终版，论文叙事）
1. **表态即正确**：Kimi/chat/coder 表态时 97.8-98.7%；共识表态 98.2%，假阳性 1.9%
2. **"敢表态"与"表态准"是独立维度**（新发现）：
   - 双优：Qwen/Kimi（67-68% 全对全 + 96-98% 表态准）
   - 敢但噪：v4-pro/MiMo（58-66% + 81-85%）——推理型模型更敢下结论但代价是误报
   - 保守但精：chat/coder（49% + 98.7%）
3. **V3→V4 代际**：v4-pro 58.4% vs chat/coder 49%——代际提升在"表态率"（50%→72%）而非"表态准确率"（98.7%→80.9% 反而降）
4. **共识增益有限**：6 模型共识 57.2% < Qwen 单模型 68.3%——"模型选择比投票更重要"
5. **金标准 A 效应**：专家评审子集上全部 +14~26pp（v4/MiMo/Kimi 90-92%）——ClinVar 标签噪声显著低估 LLM
6. **置信度校准差**：平均置信度 0.73-0.80 vs 全对全 49-68%

### 临床建议（结论）
- 筛查首选：Qwen/Kimi（高检出 + 表态准）
- 复核首选：chat/coder（表态即 98.7%）
- 流程：Qwen/Kimi 初筛 → 阳性交 chat/coder 复核 → 分歧转人工（专家评审）
- 勿用：v4-pro/MiMo 直接输出（敢表态但误报率×5）
